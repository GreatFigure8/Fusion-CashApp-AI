# Settings

Generated by `python -m cashapp.tools.settings_doc`; do not edit by hand.

Every setting except the database connection (and the few bootstrap values below) is a
DB config key. Keys are edited in Settings by an admin, with a reason, and each change
is versioned and audited. A key marked *restart* is read once when a process starts;
all others take effect on the next read (within the cache window, 15 seconds). A key
marked *secret* holds a Vault secret OCID, never the secret itself.

## Bootstrap environment

These are read from the process environment because they are needed before the database
can be read. Any other `CASHAPP_*` variable stops the process at start-up.

| Variable | Why it is not a DB key |
|---|---|
| `CASHAPP_ATP__DSN` | The database connection itself. |
| `CASHAPP_ATP__MAX_OVERFLOW` | Sizes the connection pool that reads every other setting. |
| `CASHAPP_ATP__PASSWORD` | The database connection itself (a vault reference when deployed). |
| `CASHAPP_ATP__POOL_SIZE` | Sizes the connection pool that reads every other setting. |
| `CASHAPP_ATP__POOL_TIMEOUT_SECONDS` | Sizes the connection pool that reads every other setting. |
| `CASHAPP_ATP__USER` | The database connection itself. |
| `CASHAPP_ATP__WALLET_DIR` | The database connection itself. |
| `CASHAPP_ATP__WALLET_PASSWORD` | The database connection itself. |
| `CASHAPP_ENV` | Picks the topic label and local or deployed behaviour before any I/O. |
| `CASHAPP_SECRETS__LOCAL_VALUES` | Local development only: maps a secret OCID to a value instead of calling Vault. |
| `CASHAPP_SECRETS__SIGNER` | How to sign Vault requests; needed before any secret is read. |
| `CASHAPP_SECRETS__SOURCE` | How to reach Vault; needed before any secret can be read. |
| `CASHAPP_WORKER__HEALTH_PORT` | Bound before the database is reachable and pinned by the deployment manifest. |

Also read through `cashapp.settings`: `OCI_RESOURCE_PRINCIPAL_VERSION` (injected by the
platform; selects the resource-principal signer).

### Tool-only variables

| Variable | Note |
|---|---|
| `CASHAPP_IDENTIFIER_DENYLIST` | Typer option of the anonymise CLI; not a setting. |

### Web environment

| Variable | Why it is needed before Next.js can call the API |
|---|---|
| `API_BASE_URL` | Where Next.js finds the API; needed before it can make any call. |
| `OIDC_ISSUER` | Sign-in needs the issuer before a token exists. |
| `OIDC_CLIENT_ID` | Sign-in needs the client id before a token exists. |
| `OIDC_CLIENT_SECRET / OIDC_CLIENT_SECRET_VAULT_OCID` | The confidential client's secret (or its Vault OCID); needed for the code exchange. |
| `SESSION_SECRET / SESSION_SECRET_VAULT_OCID` | Encrypts the session cookie (or its Vault OCID); needed before any session exists. |
| `APP_BASE_URL` | The OIDC redirect origin; needed before any API call. |
| `NEXT_PUBLIC_ENV_LABEL` | Inlined into the browser bundle at build time. |
