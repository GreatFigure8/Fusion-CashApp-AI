# s31-typed-web-api-client: Typed web API client and BFF proxy

- Issue: #31
- Wave: 2 (owns `web/lib/api/`, `web/app/api/`, `web/scripts/gen-api-types.mjs`)
- breaking: false

## Story

As a web developer, I want `web/` to talk to the Python API only through one client typed from the API's OpenAPI schema, so that contract drift is a type error.

## Context

CLAUDE.md *Ownership*: Next.js is a thin client; route handlers and server actions are thin proxies holding no business rules. `nextjs-fullstack-standards` `Result`-style errors and Zod at boundaries apply.

## Acceptance criteria

1. [unit] `uv run python -m cashapp.openapi_dump > web/lib/api/openapi.json` (module owned here, in `api/src/cashapp/openapi_dump.py`) and `npm run api:types` (`web/scripts/gen-api-types.mjs` runs openapi-typescript) regenerate `web/lib/api/schema.d.ts`; both generated files are committed. Merger rule recorded in the file header: on conflict, regenerate, never hand-merge.
2. [unit] `web/lib/api/client.ts` (server-only): `api<P extends keyof paths, M extends Method<P>>(method, path, { params, query, body }) -> Promise<Result<ResponseOf<P,M>, ApiError>>` that attaches `Authorization: Bearer <getAccessToken()>` and `X-Request-ID`, uses `serverEnv.API_BASE_URL`, and maps non-2xx bodies in the single error shape to `ApiError{status, code, message, requestId, details}`; network failures map to `ApiError{status: 0, code: "network_error"}`. `Result<T,E> = {ok:true,value:T} | {ok:false,error:E}` lives in `web/lib/result.ts`.
3. [unit] `web/lib/api/actions.ts`: `apiAction(fn)` helper for server actions returning a serialisable `Result`; every route handler and server action uses `api()` (or this helper).
4. [unit] SSE: `web/app/api/stream/[...path]/route.ts` proxies an allow-listed set of API streaming paths (`/flow/stream`, `/chat/stream`) with the user's token, passing the body through without buffering; `web/lib/api/use-event-stream.ts` client hook `useEventStream<T>(path, { onEvent, body? }) -> { status: "live"|"reconnecting"|"disconnected", retries, retry() }` with exponential reconnect (cap 30 s), using `fetch` + `ReadableStream` (works for POST bodies, which chat needs).
5. [unit] A lint guard (eslint `no-restricted-imports`/`no-restricted-syntax`) forbids `fetch(` to `API_BASE_URL` or `process.env.API_BASE_URL` outside `web/lib/api/`, and forbids importing `web/lib/api/client` from `"use client"` modules.
