# Plan: s34-artifact-normalisation

Issue #34. Wave 2 (same wave as s06, which calls this). Paths: `cashapp/` = `api/src/cashapp/`.
Owns `cashapp/services/normalise/` and `cashapp/domain/artifacts.py`. No LLM, no I/O, no DB, no migration.

## Standards followed

- CLAUDE.md layering: a pure business-layer function. It imports nothing from `data/`, `api/`, `pollers/`
  or `integrations/`, and never logs artifact content (PII rule; at most media types, sizes and reasons).
- research.md a3: commodity parsing from the libraries pinned by s01 (stdlib `email`, `zipfile`, `csv`;
  extract-msg, pypdf, pillow, openpyxl, python-docx, beautifulsoup4). No new dependency, no lockfile edit.
  BeautifulSoup uses the stdlib `"html.parser"` (lxml is not pinned).
- `python-web-app:building-python-web-apps`: logic in `services/`, external libraries isolated per format
  module so each is replaceable and testable.
- Pyright strict on `src/`, ruff (`S`, `B`, `RUF` …). extract-msg has no stubs: it is touched in exactly one
  module (`formats/outlook_msg.py`), which converts it into typed local dataclasses.
- s02 registries: `SourceKind` (`cashapp/domain/work_item.py`) and `ErrorCode.UNSUPPORTED_ARTIFACT`
  (s06 writes the code; this story returns the typed `Unsupported` result that triggers it).
- DRY: one recursive dispatcher; each format is one handler registered in one table; one stripping
  module; one hashing function.

## Interfaces provided (pinned)

```python
# cashapp/domain/artifacts.py
from cashapp.domain.work_item import SourceKind   # s02

@dataclass(frozen=True, slots=True)
class IncomingArtifact:
    source_kind: SourceKind
    source_ref: str              # folder path / mailbox message id; opaque to normalise
    filename: str                # "message.eml" for mail; original file name for folders
    content_type: str | None     # declared MIME type; sniffing wins over it
    data: bytes                  # the untouched original (s06 stores this, not our output)
    received_at: datetime        # tz-aware UTC
    sender: str | None = None
    subject: str | None = None

class PartKind(StrEnum):
    TEXT = "TEXT"; PDF = "PDF"; IMAGE = "IMAGE"; TABLE = "TABLE"; DOCX = "DOCX"
    # values match s06's ARTIFACT_PART.KIND column exactly

@dataclass(frozen=True, slots=True)
class NormalisedPart:
    kind: PartKind
    media_type: str      # text/plain | application/pdf | image/png | image/jpeg | text/csv | DOCX mime
    data: bytes          # reader-ready bytes: TEXT/TABLE = UTF-8 text; PDF/DOCX = original; IMAGE = PNG/JPEG
    source_path: str     # grammar below
    text: str | None     # TEXT/TABLE: the same text; PDF: text layer or None; DOCX: extracted text; IMAGE: None
    is_context: bool = False   # True only for the email-body context part appended to attachment candidates

@dataclass(frozen=True, slots=True)
class CandidateDocument:
    parts: list[NormalisedPart]   # primary parts first, context part (if any) last
    document_hash: str            # 64 lowercase hex, see document_hash()

class UnsupportedReason(StrEnum):
    UNKNOWN_FORMAT; EXECUTABLE; LEGACY_OFFICE; ENCRYPTED_PDF; ENCRYPTED_ARCHIVE;
    ARCHIVE_TOO_DEEP; ARCHIVE_TOO_LARGE; ARCHIVE_BOMB; CORRUPT; EMPTY   # value == name

@dataclass(frozen=True, slots=True)
class UnsupportedNote:
    source_path: str
    media_type: str
    reason: UnsupportedReason
    detail: str = ""            # short, never artifact content

@dataclass(frozen=True, slots=True)
class Normalised:
    documents: list[CandidateDocument]                         # always >= 1
    unsupported: list[UnsupportedNote] = field(default_factory=list)  # part-level notes (AC5)

@dataclass(frozen=True, slots=True)
class Unsupported:
    reason: UnsupportedReason
    media_type: str
    notes: list[UnsupportedNote] = field(default_factory=list)  # every rejected piece, for the history row

type NormalisationResult = Normalised | Unsupported
```

`source_path` grammar: segments joined by `/`, starting with the top filename; container members appended
(`msg.eml/attachments/remit.zip/2024/a.pdf`); fragments after `#`: `#body`, `#sheet=<name>`,
`#frame=<n>` (1-based), `#context`. Stable and unique within one artifact.

Consumers: s06 (`IncomingArtifact`, `normalise`, `Normalised`, `Unsupported`, `PartKind`, `NormalisedPart`
fields → `ARTIFACT_PART` rows; it should record `unsupported` notes on the history row so nothing is silently
dropped); s08 readers consume `NormalisedPart` (they send `text` for TEXT/TABLE/DOCX, bytes for PDF/IMAGE,
and may label `is_context` parts as "covering email"); s35 via s06's `ingest`.

## Behaviour (what the coder implements)

1. **Sniff** (`sniff.py`), magic bytes first: `%PDF-` pdf; PNG/JPEG/GIF/TIFF(`II*\0`,`MM\0*`)/BMP/RIFF-WEBP;
   `PK\x03\x04` → inspect names: `word/document.xml` docx, `xl/workbook.xml` xlsx, else zip; OLE
   `D0CF11E0` → `.msg` if extract-msg opens it as a message, else `LEGACY_OFFICE` (.xls/.doc); `MZ` →
   `EXECUTABLE`; RFC 822 header block (`From:`/`Received:`/`MIME-Version:` lines before a blank line) or
   declared `message/rfc822` → eml; `<html`/`<!doctype html` → html; UTF-8/cp1252 decodable with `.csv`
   extension or declared `text/csv` → csv; decodable text → text/plain; else `UNKNOWN_FORMAT`.
   Zero bytes → `EMPTY`.
2. **Formats** (one handler each):
   - text/plain → TEXT. HTML → BeautifulSoup `html.parser`; drop `script/style/head`; each `<table>` replaced
     by TSV rows (cells `\t`, rows `\n`, cell whitespace collapsed); `<br>`/block elements → newlines.
   - PDF → one PDF part (original bytes); `text` = pages' `extract_text()` joined by `\f`, `None` if blank.
     `reader.is_encrypted` → `ENCRYPTED_PDF` (no decrypt attempt; see Assumptions). Parse error → `CORRUPT`.
   - PNG/JPEG → IMAGE as-is. TIFF/GIF/BMP/WEBP → one PNG IMAGE part per frame (`ImageSequence`, ≤
     `max_image_frames`, extra frames noted), saved with no metadata so bytes are stable.
     `Image.DecompressionBombError` → `ARCHIVE_BOMB`.
   - XLSX → `openpyxl.load_workbook(read_only=True, data_only=True)`; each sheet with any non-empty cell →
     TABLE part, `text/csv`, CSV via `csv.writer` (`lineterminator="\n"`); Decimal/float via `str`, dates ISO,
     None → empty. Workbook = one document with one TABLE part per sheet.
   - CSV → TABLE part re-encoded as UTF-8 (BOM removed, newlines normalised).
   - DOCX → DOCX part (original bytes, its mime type); `text` = paragraphs and tables (TSV) in document order.
   - eml → `email.parser.BytesParser(policy=policy.default)`. Body = `text/plain` alternative else HTML →
     text. Body text is prefixed with `From:`, `Subject:`, `Date:` lines from the headers (the reader needs the
     payer) and passed through `strip_body(is_forward=subject starts FW:/Fwd:/Fw:)`. Attachments: every part
     with a filename or `attachment` disposition, plus inline non-text parts; a `cid:`-referenced inline image
     smaller than `min_inline_image_bytes` is a signature logo → recorded as a note
     (`UNKNOWN_FORMAT`, detail "inline decoration") rather than a candidate. `message/rfc822` parts recurse.
   - msg → `open_msg(data) -> MsgContent{sender, subject, date, body_text, body_html, attachments:
     list[MsgAttachment{filename, data | nested MsgContent}]}`; then the same assembly as eml.
   - zip → `zipfile.ZipFile`; reject before reading if member count > max, any `flag_bits & 0x1`
     (`ENCRYPTED_ARCHIVE`), declared total > remaining budget (`ARCHIVE_TOO_LARGE`), or per-member ratio >
     max (`ARCHIVE_BOMB`); read members in bounded chunks and stop when the cumulative budget is exceeded
     (headers are not trusted). Directories and `__MACOSX/`, `.DS_Store` skipped silently-by-rule (noted).
     Depth > `max_depth` → `ARCHIVE_TOO_DEEP`.
3. **Strip** (`strip.py`), line-based, applied to email bodies only: cut from the first match to the end for
   `^On .{1,200} wrote:$` (also wrapped across two lines), `^-{2,}\s*Original Message\s*-{2,}`, an Outlook
   header block (`From:` followed within 4 lines by `Sent:`/`Date:` and `To:`/`Subject:`), signature
   delimiter `^-- ?$`, disclaimer markers (case-insensitive: `CONFIDENTIALITY NOTICE`, `DISCLAIMER`,
   `This e-?mail and any attachments`, `This message (and any attachments )?is intended only`,
   `Please consider the environment before printing`), and a trailing sign-off (`Regards|Best regards|
   Thanks|Thank you|Sincerely|Cheers`,) followed by ≤ 6 short lines to the end. Drop `>`-quoted lines.
   When `is_forward`, header blocks and `---------- Forwarded message ---------` lines are removed but the
   content below them is kept (the remittance is usually the forwarded content). Collapse 3+ blank lines.
   The original bytes are untouched (s06 stores them); only the stripped text goes into the TEXT part.
4. **Heuristic** `body_looks_like_remittance`: True if (a) an invoice-like token: a keyword
   (`inv(oice)?|credit memo|cm|bill|doc(ument)?`, case-insensitive, optional `#`/`no.`/`:`) followed within
   3 tokens by an alphanumeric token with ≥ 4 digits (optional `-\d{1,2}` suffix), or (b) an amount table:
   ≥ 2 lines each holding an amount (`\d{1,3}(,\d{3})*\.\d{2}` or `\d+\.\d{2}`) and a tab or 2+ spaces
   separating ≥ 2 fields. Phone numbers and dates alone never match (tested).
5. **Assemble** (`assemble.py`), per email (top-level or nested):
   - each standalone attachment that yields parts is its own candidate (PDF, image (all frames of one file
     = one candidate), workbook, CSV, DOCX); a nested eml/msg or zip contributes its own candidates
     recursively;
   - the body is its own candidate iff `body_looks_like_remittance(stripped)`; otherwise, if there is ≥ 1
     attachment candidate, the stripped body is appended as a `TEXT` part with `is_context=True`,
     `source_path=…#context` to every candidate of that email (including nested ones); if there are no
     attachment candidates, the body is the sole candidate regardless (classify decides);
   - empty stripped body → no body part.
   - Non-email top-level artifact: one candidate (zip: one per member document).
   - Result: ≥ 1 candidate → `Normalised(documents, unsupported=notes)`; none → `Unsupported(reason of the
     top-level/first note, media_type of the top artifact, notes)`.
6. **Hash**: `document_hash` per the pinned rule; computed once in `CandidateDocument` construction.

## Assumptions (deviations logged)

- **`document_hash` excludes `is_context` parts.** AC6 says "ordered part bytes"; including the covering-email
  context would make the same remittance PDF forwarded twice with different cover notes hash differently and
  defeat s06's child-level dedupe (prior lessons: "the same remittance is often submitted twice"). Framing is
  length-prefixed to avoid concatenation collisions.
- **Additive fields beyond the story signature** (all defaulted, non-breaking for s06): `NormalisedPart.is_context`,
  `Normalised.unsupported` (the AC5 "part-level unsupported note"), `Unsupported.notes`, `IncomingArtifact`
  `sender`/`subject` default `None`, `normalise(..., limits=DEFAULT_LIMITS)`. `UnsupportedReason` is a StrEnum
  so `reason` still reads as a string.
- Result types live in `cashapp/domain/artifacts.py` (pure) and are re-exported from
  `cashapp/services/normalise/__init__.py`, the import path s06 pins.
- Any encrypted PDF is unsupported (even owner-password-only): decrypting AES needs `cryptography`, which is
  not pinned, and readers can't take encrypted PDFs reliably.
- Legacy `.xls`/`.doc` are unsupported (no xlrd/antiword pinned); revisit if real traffic shows them.
- BMP/WEBP are also converted to PNG (readers get PNG/JPEG only), beyond the story's TIFF/GIF list.
- Email headers (From/Subject/Date) are prefixed to the body TEXT part so readers see the payer.
- Fixtures are generated in memory instead of checked-in binaries, keeping this story file-disjoint from s06's
  `api/tests/fixtures/artifacts/`; s06 may reuse the builders.
- `normalise` is synchronous; s06 must call it through `asyncio.to_thread` (documented in the docstring).

## Risks

- **`.msg` fixture:** no pure-Python `.msg` writer exists. The coder first tries to obtain/create a small
  synthetic `.msg` (e.g. with Outlook if present on the host) at `api/tests/fixtures/normalise/sample.msg`;
  otherwise `test_msg_fixture_real_file` skips with an explicit reason and the extract-msg mapping is
  covered through the `open_msg` seam. The extract-msg API (`openMsg` on bytes, `attachments`, embedded-message
  attachments, `htmlBody` bytes) must be confirmed against the locked version before coding the adapter.
- **Stripping false positives** could remove a remittance (e.g. a remittance pasted below "Thanks,").
  Mitigation: sign-off cut only when ≤ 6 short lines follow; forwarded content kept; originals always in
  Object Storage; tests include a remittance below a greeting.
- **Heuristic misses** only cost a split (the body then rides as context), never data.
- **Zip-bomb guard** must not trust headers: chunked reads against the cumulative budget are mandatory.
- **pypdf text extraction** can be slow on large PDFs; acceptable on the to_thread path; no page cap now.
- **Pillow `MAX_IMAGE_PIXELS`** left at its default; the bomb error maps to `ARCHIVE_BOMB`.
- Very large images are not downscaled here (reader limits are s08's concern).
- Pyright strict vs openpyxl/extract-msg partial typing: confined to two modules with typed wrappers; no
  blanket ignores.
